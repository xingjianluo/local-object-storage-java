# local-object-storage-java-bootstrap

基于 Spring Boot 3 / Java 21 的**本地对象存储服务**：用本地磁盘模拟对象存储后端，
支持分片上传与断点续传、对象版本、内容级去重，在并发交错与异常中断下保持一致、可解释。

## 快速开始

```bash
mvn test            # 运行全部测试（15 个用例）
mvn spring-boot:run # 启动服务（默认存储到 ./data/storage，默认端口 8080）
```

## 能力一览

- 分片上传：会话创建后分片可**乱序、重复、重试**；单片大小 + SHA-256 校验、整体合并再校验；
  只有合并与版本提交都成功后对象才可见；中断/过期/中止不产生可见对象。
- 对象版本：同名对象每次上传产生新版本，历史版本可读、可删、可回滚；回滚以追加新版本实现。
- 内容去重：内容按 SHA-256 寻址，相同内容（跨版本/跨对象）物理上只存一份，
  引用计数以磁盘标记文件为准，删除/覆盖/回滚后可对账、可回收。
- 并发与回收：分层加锁（会话锁 → 对象锁 → blob 锁，全局固定顺序），
  活动读者计数保证回收期间要么读完整数据要么明确失败；
  大对象顺序流式合并，内存占用恒定（默认 64KiB 缓冲，与对象大小无关）。
